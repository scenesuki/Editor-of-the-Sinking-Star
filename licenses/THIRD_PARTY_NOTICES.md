## Design reference

The [ootss-cmd](https://github.com/qiekn/ootss-cmd) reference repository is not included or loaded at run
time. This project used it as a design and game-layout reference; its custom
license is preserved in [ootss-cmd-LICENSE.txt](ootss-cmd-LICENSE.txt) in acknowledgement.

No fonts, game executable, game save or private project is bundled. Fonts are
selected from Windows, with system fallback. No network service is required
for normal operation.
