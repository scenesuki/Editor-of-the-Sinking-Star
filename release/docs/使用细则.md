# 使用细则

[返回 README](../README.md) · [English](USAGE.en.md)

适用于 `0.1.0-preview`。适用于便携包与随附独立源码的便携数据布局。**录制全部使用短按；建议先备份，再开始编辑。**

## 1. 启动与界面

- 完整解压到可写目录，不在 ZIP 内运行；先打开游戏，再运行 `SinkingStarEditor.exe` 加载面板。输入助手 `SSEKeyWorker.exe` 无需手动启动。
- 按一次反引号／波浪号键切换鼠标模式，再按一次返回游戏，**无须长按或按 Shift**。鼠标模式下操作面板不会录入游戏动作。
- 录制、播放或试调成功启动后自动退出鼠标模式；失败时保留界面。播放中开启鼠标模式会停止发送；失焦会退出鼠标模式并停止自动输入。
- 语言首次跟随 Windows 显示语言，中文系统用简体中文，其余用英文；可手动切换并记住。
- 工具键和鼠标切换键可在未打开工程时设置；冲突须先解决。两个默认延迟仅在工程打开且结束录制／播放后修改，点击“应用延迟”并保存。

## 2. 工程与录制

| 操作 | 行为 |
| --- | --- |
| 新建工程 | 原生保存当前战役，复制固定起点，载入工具临时副本并开始录制 |
| 打开工程 | 从固定起点创建并载入新副本，不自动录制 |
| 进入编辑状态 | 保持当前现场，在时间轴末尾追加；不读档、不重放，现场同步由你判断 |
| 从头播放 | 重新载入固定起点，再执行脚本 |
| 保存 | 保存脚本与本工程参数，不更新固定起点 |
| 退出工程 | 保存修改、停止发送并释放持键，载入进入前战役后清理所属临时副本 |

原存档（包括首个 `default`）和固定起点不随临时副本的自动保存更新。恢复结果以**游戏原生读档**为准，动画等瞬时状态可能变化，不是完整内存恢复。

### 默认按键

| 按键 | 用途 |
| --- | --- |
| W／A／S／D、1～9、X／V | 方向、人物、激活及拿放；实际按键跟随游戏设置 |
| 游戏撤销键（默认 Z） | 撤销游戏操作，并移除最近普通动作记录 |
| E | 仅删除最近动作记录，不操作游戏；有待用 T 时优先取消它 |
| T | 为下一动作插入额外等待标记，不强制游戏现场等待 |
| P | 预览包停用；旧 P 步骤可替换／删除，包含 P 的播放片段会提前拒绝 |

E／T 和鼠标切换键可配置，人物数字是固定编号。一次按下只记一条，不保存真实按键间隔；长按可能让游戏重复动作而记录只有一次。Z／E 可影响此前轮次，已写入的等待保留；撞墙等导致两边撤销不一致时，用 E 修正记录。未支持的游戏动作可能停止录制。

## 3. 时间轴、等待与倍速

- **先结束录制／播放，再编辑。** 点击动作或等待开二级窗；“＋添加”插在选中行后，未选中则追加，只改脚本、不操作游戏。
- 按住行左侧拖动柄排序，靠近上下边缘自动滚动；拖出列表、Esc、失焦或关闭鼠标模式可取消。手动滚动暂停跟随，点击“回到当前步骤”恢复。
- 编辑撤销／重做仅修改脚本，不发送游戏 Z、不读档；保留最多 50 次／32MiB，本次工程会话内有效。时间轴上限 65,536 条。
- 普通间隔默认 **250ms**，T 默认额外等待 **1000ms**；各工程独立保存。`动作 A → 等待 1000ms → 动作 B` 的间隔为 **250＋1000＝1250ms**。更改默认额外等待不覆盖已有条目；结束录制会丢弃尚未用于动作的 T 标记。
- 修改前面的动作、顺序或等待可能使后续等待待复核、检查点失效；删除步骤不会撤回游戏现场。
- 工程内可选暂停／0.25×／1×／4×。暂停保留录制但不接收游戏动作；速度不写脚本、不缩放真实毫秒。自动播放、准备起点和试调固定 1×且锁定调速，结束保持 1×；退出时恢复接管前速度。

## 4. 延时试调

以 `动作 A → 等待 T → 动作 B` 为例：

1. 点击等待条目打开窗口，再点“准备起点”：从固定起点播放到 **A 执行前**并保存原生检查点。
2. 修改等待值，点“开始试调”：每次先恢复检查点，再执行 **A → 普通间隔＋T → B**，随后停止发送，由你判断结果。
3. “返回起点”只恢复、不播放；满意后点“应用并标记已调”，再保存工程。

缺少 A 或 B、存在连续等待时禁止试调；连续等待由你手动修改／删除，不自动合并。关闭窗口停止任务但不回退。检查点管理仅在确认后清理可核验的历史项，保留当前引用和未识别材料。

## 5. 备份、退出与异常

- **备份／恢复前关闭游戏和编辑器。** 用 `SaveBackup.exe` 选择游戏存档根目录 `Order of the Sinking Star`，不要选 Steam 安装目录。备份位置默认 `data/save-backups/`，可另选磁盘；每次独立保留，不自动清理。
- 恢复先校验备份并预备份当前目录，再经确认完整回滚全部战役及目录内设置／键位。后来新增的战役会移出当前目录，仍保存在预备份里；不会混合新旧文件。工具不管理平台云同步。
- 正常离开用“退出工程”或“退出并卸载”。失败时保留材料，按面板恢复提示处理；不要强删 `session.json`、临时战役或恢复记录。
- 恢复中断时保持游戏关闭，使用“完成上次恢复”。应急恢复会保留并作废可确认受影响的本地旧会话，之后从工程固定起点建立新会话。
- 异机、异用户或无法核验的旧未结束会话禁止自动恢复／清理，须先在原环境安全退出。恢复草稿不保证断电／强制终止前每个按键均已落盘。
- 更新前先安全退出，替换程序时保留整份 `data/`；工程迁移暂不支持。报错时保留文件并查看日志，分享日志前移除个人信息。

## 6. 兼容与文件位置

仅支持 Windows 10／11 x64 和以下完整游戏 EXE SHA256；未知构建拒绝连接。新版可原生读取旧工程副本，旧游戏拒绝新版工程／检查点。

```text
0ae10a513dae25286fe93d0db4fa8a2df9a473bc07e1734e12bc1ad30166db1c
d802098b7cb85eadfc733b88d1554042fad950c572e916febea3f669a474a549
```

| 位置 | 内容 |
| --- | --- |
| `data/projects/` | 工程、固定起点、脚本与检查点 |
| `data/save-backups/` | 默认完整存档备份 |
| `data/config/` | 语言、工具键等配置 |
| `data/logs/` | 日志及运行恢复材料 |

以上目录都在程序旁，首次运行后生成。目录不可写时，将整套程序移到可写位置。不要单独移动 EXE 或删除必需运行文件。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 按钮无法点击 | 先按已设置的鼠标切换键；默认是反引号／波浪号键 |
| 无法连接游戏 | 先打开游戏，核对上方完整 EXE 指纹；未知版本不强行连接 |
| 无法录制／播放 | 先解决键位冲突；预览版脚本含 P 时须替换或删除 |
| 无法返回原存档 | 保留工程、临时副本与恢复记录，按面板提示重试；不要强删文件 |
| 手册未以排版模式打开 | `.md` 可用文本编辑器阅读；启动器无默认关联时用记事本打开 |

预览包不支持自动播放调速、工程跨设备迁移、女王直选、长按／组合键或手柄录制。异机、显卡、缩放和输入法尚未全面验收，游戏动作与路线结果由使用者判断。反馈问题时附版本、复现步骤和脱敏后的日志。
